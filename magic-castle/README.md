# Magic Castle · 魔法城堡

> 恶龙来袭，城堡陷入危机。公主举起法杖：
>
> **「这一次，就由我来守护这一切吧！」**

《Magic Castle》是一款以魔法公主守护城堡为主题的 2D 试玩广告游戏。玩家在短时间内抵御怪物、抽取强化卡牌，并迎战体型庞大的恶龙。

## 创作灵感

灵感来自曾在抖音走红的「骑士小猫」：可爱的小猫面对体型庞大的恶龙，强烈的反差既有趣，也很容易吸引目光。

我想把这种反差带进自己的游戏，让一位可爱的魔法公主站在恶龙面前。谁说公主一定要等着骑士来救？这次，公主自己上！

## 设计思路

试玩广告的时间很短，需要在短时间内抓住注意力，也要让玩家迅速感受到战斗和成长的乐趣。因此，我围绕快节奏、随机惊喜和直观的变强体验设计了游戏。

### 快节奏战斗

配合节奏明快的音乐，让玩家快速进入守护城堡的战斗，击退不断靠近的怪物，最终面对恶龙。

### 抽卡与骰子：下一次会得到什么？

战斗中可以获得强化卡牌。随机出现的选择带来期待，抽到想要的强化时也会更有惊喜感。

玩家还可以选择掷骰子，随机获得强化卡：掷出 **4、5 或 6 点**时，还能额外获得一张卡牌。来看看今天欧不欧！

### 卡牌强化：能叠起来就起飞了

强化卡牌可以重复获取、叠加效果。例如「连击印记」增加每次点击的攻击次数，「散射星辉」增加弹道数量。

前期还在一下一下地攻击，随着强化不断叠加，画面里的攻击也逐渐密集起来，直到火力全开。这种看得见的从弱到强，正是我想呈现的爽感。

### 龙卷风：带点小心思的技能

龙卷风会吸引范围内的怪物，并对它们造成伤害。除了技能效果，我还加入了一个有趣的小细节：

- 技能释放时，公主头顶会出现「站在这里会回血」的特效贴纸。
- 怪物头顶先冒出问号，再慢慢朝龙卷风走去——就好像它们真的相信那里可以回血一样。

## 未来构想：技能组合

**以下是尚未完成的设计构想。** 我希望不同卡牌搭配后能产生意想不到的效果，而不只是提高伤害数值。

构想中的其他卡牌包括火焰沼泽、穿云箭、花瓣舞和潮流击退，例如：

| 组合 | 构想效果 |
| --- | --- |
| 龙卷风 + 火焰沼泽 | 扩大火焰沼泽的范围 |
| 穿云箭 + 火焰沼泽 | 穿云箭附带灼烧效果 |
| 花瓣舞 + 普攻 | 花瓣舞为敌人附加印记，普攻引爆印记 |

考虑到试玩广告的时长有限，如果一次加入太多技能和组合，玩家可能还没弄明白玩法，试玩就结束了。因此目前优先保证核心玩法，让玩家快速体验抽卡、强化和战斗的乐趣。

## 打开项目

项目使用 **Cocos Creator 3.8.4** 和 TypeScript 开发。

1. 使用 Cocos Creator 3.8.4 打开 `magic-castle` 项目目录。
2. 打开 `assets/scenes/BattleScene.scene` 场景。
3. 在编辑器中运行预览。

主要脚本位于 `assets/scripts/`：

- `GameManager.ts`：游戏状态、经验、强化卡牌和骰子奖励。
- `BattleManager.ts`：敌人、攻击、龙卷风和战斗逻辑。
- `UiManager.ts`：游戏界面、卡牌选择和骰子表现。
- `IntroController.ts`：开场演出。
